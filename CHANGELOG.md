# Changelog

## 0.0.2-beta

- Fixed `/oauth/token` request body encoding to send `application/x-www-form-urlencoded` (`URLSearchParams`) instead of `application/json` as required by OAuth 2.0 specifications.

## 0.0.1-beta

- Initial beta release of `liquid-js-sdk`.
- Universal (browser + Node.js 18+) zero-dependency client SDK for the Liquid authentication platform.
